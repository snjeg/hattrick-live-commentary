# 0003: CHPP licence constraints

Status: open until Hattrick answers the licence request.

Facts from the CHPP Product License text: documented XML files only; OAuth 1.0a; never ask for or store logins; no sharing of Hattrick data with other services without consent (5.2); no automated access without explicit consent (5.3); automated downloads limited to once a day per account or page unless otherwise agreed (5.4); functional description must be approved before release and kept up to date (4.1); published privacy policy (8.1); declare Chrome Web Store distribution (7.1).

Consequences: no automated live polling code until Hattrick's written consent is recorded here. Development and testing use the developer's own team's live data. Context files are fetched once per team and cached.

Record here: date of consent, scope (live polling, context files, voice providers), and any limits Hattrick sets.
